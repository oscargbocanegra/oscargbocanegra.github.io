Trabajá Conmigo

Empezá por el problema, no por un formulario comercial.

Una forma simple de conversar sobre una iniciativa de IA o datos que necesita dirección técnica senior y apoyo de entrega.

Hablemos de tu Proyecto

Compartí solo el contexto necesario para iniciar una conversación técnica. El sitio no almacena datos del formulario ni promete un tiempo de respuesta.

Qué información enviar

Tu nombre, correo profesional, una breve descripción del problema o iniciativa y cualquier contexto no sensible que ayude a enmarcar la conversación. El estado actual y las restricciones son útiles si los tenés.

Qué pasa después

Al enviar el formulario, tus datos son recibidos directamente para su revisión.

  1. Revisar: considerar el contexto no sensible compartido.
  2. Aclarar: alinear el problema, las restricciones y el resultado esperado.
  3. Definir: identificar un siguiente paso práctico o modalidad de colaboración.
  4. Colaborar: decidir si existe una forma útil de trabajar juntos.

Si preferís no usar el formulario, usá {{ site.email }} o escribí por LinkedIn (se abre en una nueva pestaña).

Encaje de colaboración

Mejor para trabajo claro y colaborativo.

El mejor encaje incluye equipos empresariales, consultoras, startups o scale-ups y equipos que necesitan arquitectura más implementación práctica. También parte de un problema significativo, contexto no sensible y un interés práctico en tomar decisiones técnicas informadas. El objetivo es dar claridad sobre la iniciativa, sus restricciones y el siguiente paso útil, no iniciar un proceso comercial genérico.

Evidencia y trayectoria

La evidencia pública y la experiencia empresarial se mantienen separadas.

El caso técnico destacado es trabajo público independiente. El CV resume la experiencia profesional y empresarial. Este sitio no afirma resultados de clientes, disponibilidad, precios ni compromisos de respuesta.
