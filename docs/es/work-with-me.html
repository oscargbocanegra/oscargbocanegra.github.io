Trabajá Conmigo

Empezá por el problema, no por un formulario comercial.

Una forma simple de conversar sobre una iniciativa de IA o datos que necesita dirección técnica senior y apoyo de entrega.

Contexto del proyecto

Compartí solo el contexto necesario para iniciar una conversación técnica. El sitio no almacena datos del formulario ni promete un tiempo de respuesta.

Cómo funciona este contacto

Al completar los campos requeridos, el botón prepara un correo en tu aplicación de correo configurada. Revisalo antes de enviarlo.

Si no se abre una aplicación de correo, usá {{ site.email }} o escribí por LinkedIn (se abre en una nueva pestaña).

No se envía un formulario ni se conserva información en este sitio.

Modalidades

Elegí la modalidad según la iniciativa.

Proyecto definido

Para un resultado de arquitectura o implementación delimitado.

Entrega por contrato

Para capacidad senior dentro de un equipo activo.

Arquitectura fraccional

Para dirección técnica continua en decisiones de IA y datos.

Evidencia y trayectoria

La evidencia pública y la experiencia empresarial se mantienen separadas.

El caso técnico destacado es trabajo público independiente. El CV resume la experiencia profesional y empresarial. Este sitio no afirma resultados de clientes, disponibilidad, precios ni compromisos de respuesta.
